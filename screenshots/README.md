# Screenshots

This folder should contain at least 5 screenshots as required by the assignment brief.

## Required screens (desktop + mobile):

1. `01-dashboard-desktop.png` — Dashboard with stats, chart, appointments, goals
2. `02-activities-desktop.png` — Activities list with filter + search
3. `03-appointments-desktop.png` — Appointments list with status tabs
4. `04-progress-desktop.png` — Progress page with charts
5. `05-goals-desktop.png` — Goals page with progress bars
6. `06-modal-form.png` — Add activity / book appointment modal form open
7. `07-mobile-dashboard.png` — Dashboard on mobile viewport (375px)
8. `08-mobile-sidebar.png` — Mobile sidebar drawer open

## How to take screenshots:

1. Run `npm run dev` and open http://localhost:5173
2. Use browser DevTools (F12 → Toggle device toolbar) for mobile views
3. Use a screenshot tool or browser built-in (right-click → Screenshot in Firefox)
